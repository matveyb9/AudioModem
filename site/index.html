01 / Модель канала

Аудио — это транспорт.

N1 собирает объект, ADLP превращает его в кадры, модем создаёт PCM. N2 выполняет обратный путь и публикует файл только после проверки. Канал доставки не меняет объект и его контроль целостности.

02 / Профили

Скорость — это настройка. Надёжность — это выбор.

Пресет задаёт параметры физического профиля, но не меняет формат объекта. Приёмник читает устойчивый bootstrap control frame и сам выбирает нужный демодулятор.

03 / Начните воспроизводимо

Первый канал — WAV.

WAV исключает неизвестный аудиомаршрут из первой проверки. Сначала соберите текст в WAV, передайте файл любым способом, затем декодируйте и проверьте исходный объект.

CLI / bootstrapcargo run -p adlp-cli -- encode-text hello.wav N1 "Привет" reliablecargo run -p adlp-cli -- decode hello.wav

Базовый WAV-профиль — детерминированный bootstrap для проверки контейнера, а не заявление об устойчивой передаче по воздуху.
