Быстрый старт: проверка WAV-передачи

Начните с lossless файла до проверки неизвестного live-audio route.

  1. Соберите workspace. Bootstrap CLI упаковывает text в ADLP v1 object и создаёт mono 48 kHz PCM WAV.
  2. Передайте WAV-файл. Любой обычный файловый канал переносит этот первый reference transport.
  3. Декодируйте и проверьте. Приёмник проверяет framing и final ADLP integrity до возврата object.

CLI / bootstrap

cargo run -p adlp-cli -- encode-text hello.wav N1 "Привет из AudioModem" reliable
cargo run -p adlp-cli -- decode hello.wav

Bootstrap mapper намеренно прост. Это не robust over-the-air acoustic modulation scheme.

Протокол

Versioned object, а не route

ADLP определяет object до того, как physical profile превратит его в PCM. Будущий Acoustic-1 изменит mapper, но не wire object.

Спецификация ADLP v1 ↗
Явная trust boundary

Позывной — открытая display metadata, а не identity proof. Encryption и key exchange потребуют публичного RFC и security review.
